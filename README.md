# Portfólio Pessoal - Nycolas Robert Batista Ramos

## Descrição

Projeto desenvolvido para a disciplina de desenvolvimento web,
com o objetivo de apresentar informações pessoais, formação,
experiência profissional, habilidades e recursos multimídia.

## Autor

Nycolas Robert Batista Ramos

## Tecnologias utilizadas

- HTML5
- CSS
- Canvas
- SVG

## Estrutura do projeto

- index.html - Página inicial
- curriculo.html - Currículo
- formulario.html - Formulário de contato
- multimidia.html - Recursos multimídia
- graficos.html - Canvas e SVG
- css/estilos.css - Folha de estilos externa
- img/ - Imagens utilizadas no projeto
- media/ - Arquivos multimídia

## Atualização CP2

- Abordagem mobile-first
- Flexbox no cabeçalho/menu e na seção de interesses
- CSS Grid responsivo no currículo, multimídia e gráficos
- Media queries com `min-width`
- Mídias responsivas
- Áreas de toque de aproximadamente 44 px em links e botões
- Layout preparado para telas a partir de 320 px sem rolagem horizontal da página

## Recursos implementados

- HTML semântico
- Menu de navegação entre páginas
- Formulário com validação nativa
- Áudio com controles
- Iframe funcional
- SVG estilizado com CSS
- Layout responsivo
